# Мобильное приложение MyCalendar

Современное и минималистичное приложение для управления задачами и расписанием для Android. Проект полностью написан на **Kotlin** с использованием **Jetpack Compose**. Основной фокус сделан на чистую архитектуру, плавный пользовательский опыт и эффективную работу с локальными данными без необходимости подключения к интернету.

## ✨ Ключевые возможности

* **Таймлайн дня:** Кастомный интерфейс для планирования и визуализации задач на динамической почасовой сетке.
* **Умные напоминания:** Локальные фоновые уведомления с использованием `AlarmManager` для точного срабатывания даже при закрытом приложении (за 5 минут и ровно во время старта задачи).
* **Мировые часовые пояса:** Встроенный поиск по глобальной базе IANA Time Zone для мгновенной адаптации расписания под любой город мира.
* **Управление задачами:** Создание, редактирование и удаление задач с возможностью установки приоритетов (Срочно/Важно) и описаний.
* **Современный UI:** Просторные отступы, скругленные элементы интерфейса и аккуратная типографика с использованием шрифта HelveticaNeue.

## 🛠️ Стек технологий и архитектура

Проект разработан с использованием современных практик Android-разработки для обеспечения масштабируемости и чистоты кода:

* **UI-фреймворк:** Jetpack Compose, Material 3
* **Язык программирования:** Kotlin
* **Архитектура:** MVVM (Model-View-ViewModel) + элементы Clean Architecture
* **Внедрение зависимостей (DI):** Dagger Hilt
* **Локальная база данных:** Room
* **Асинхронность:** Kotlin Coroutines & StateFlow
* **Фоновые задачи:** BroadcastReceiver & AlarmManager
